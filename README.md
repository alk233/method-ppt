# method-ppt · 讲解型 PPT 制作技能

用于论文组会、课程汇报和技术方案讲解的 Codex 技能。它把材料阅读、方法叙述、公式解释、模板沿用、批注修改和逐页口播整理成可复用的工作规则。

适合已有论文或技术材料，希望把方法讲清楚，并持续修改同一份 PPT 的场景。技能包含制作指引和验收标准；实际读写、渲染和导出 PPT 需要运行环境提供相应工具。

## 它关注什么

| 环节 | 默认做法 |
| --- | --- |
| 内容组织 | 从问题、场景和贡献讲起，再讲框架、机制、算法、实验与局限；按本次任务决定页数和深度。 |
| 模板沿用 | 保留用户提供的母版、标志、字体、配色和标题层级，按原有图文关系排版。 |
| 公式讲解 | 展示完整公式，在对应项下方用括号和简短说明解释作用；说明中的数学符号保留上下标和字形。 |
| 算法讲解 | 先查原文、附录与官方补充材料；自行整理时标明来源性质，保留公式、控制结构和关键子过程。 |
| 实验证据 | 优先使用原论文图表截图，分别解释子图、比较条件、指标和结论，区分结果与推测。 |
| 局部修改 | 以最新文件和批注为准，保护用户指定原话与未涉及内容，修改后检查裁切、遮挡和溢出。 |
| 正文与口播 | 中文文本检查空话、重复和模板化表达；口播按最终页序编写，默认平淡流畅，直接陈述。 |
| 交付验证 | 核对材料依据与符号，渲染检查页面，并说明实际完成的检查及未验证项。 |

这些都是可调整的默认偏好。本次明确要求优先；只问概念含义时，先在聊天解释，不自动修改文件。

## 环境与配套技能

仓库只包含指令、参考规则和界面元数据，没有安装脚本、PPT 模板、论文附件或生成引擎。

- **制作 PPT 所需能力**：读取与编辑演示文稿、导出文件、渲染预览。优先遵循当前环境的 `presentations` 技能，也可以使用其他适用的演示文稿专用技能及工具。
- **中文润色**：默认调用 `humanizer-zh` 检查正文与口播。这里的“去 AI 味”指改善表达，不承诺通过检测器。
- **按任务选用**：论文理解可配合 `paper-reading-zh`；科研叙述和模板制作可配合 `scientific-slides`、`ppt-master`；PDF 截图或导出使用相应 PDF 技能。

以上配套技能均未随本仓库分发。使用前检查它们是否可用、是否具有所需工具权限；缺少能力时说明限制，不能把大纲当成已完成的 PPT，也不能声称运行过未执行的校验。

## 安装到 Codex

如果当前环境提供 `skill-installer`，可以直接对 Codex 说：

```text
使用 $skill-installer 安装 https://github.com/alk233/method-ppt/tree/main/skills/method-ppt
```

也可以手动安装：

下载或克隆本仓库，将 **`skills/method-ppt` 整个文件夹**复制到以下任一位置：

| 范围 | 安装后的入口 |
| --- | --- |
| 当前项目 | `<项目目录>/.agents/skills/method-ppt/SKILL.md` |
| 当前用户 | `~/.agents/skills/method-ppt/SKILL.md` |

`~` 表示当前用户的主目录。保留 `agents` 和 `references` 子目录，只复制 `SKILL.md` 会丢失详细规则。已有同名技能时先对比并备份，不直接覆盖个人修改。

Codex 支持自动发现技能；未显示时重新启动会话或应用。安装位置和调用方式见 [官方技能文档](https://learn.chatgpt.com/docs/build-skills)。本仓库提供可手动安装的技能文件，尚未打包为插件。

## 使用示例

将论文、模板或待修改的 PPT 提供给运行环境，再说明任务。以下文件名仅用于示例。

**从论文制作汇报：**

```text
使用 $method-ppt，根据 paper.pdf 和 template.pptx 制作组会汇报。
控制在 18 页以内，重点讲清方法、公式各项作用和实验依据。
沿用模板，实验图表使用原论文截图，交付可编辑 PPTX。
```

**根据批注局部修改：**

```text
使用 $method-ppt，在当前 PPT 上修改第 6 页。
把这条损失函数放在同一行，按项解释作用，符号保留上下标。
左侧原文截图和其他页面保持原样。
```

**编写逐页口播：**

```text
使用 $method-ppt，读取最终版 PPT，写一份 15 分钟的逐页口播稿。
正文和口播都做中文润色，语气平淡流畅。
直接说明方法，不用“那么问题来了”之类的设问转场。
```

## 调整为自己的习惯

日常任务可直接覆盖默认偏好，例如听众、时长、详略和模板。长期偏好放在 `SKILL.md`，专题规则放在对应参考文件，避免将一次性的论文术语、页码和路径写成固定要求。

公开分享时只保留可复用的制作方法。个人署名、机构标志、未公开构想、原始论文附件和项目文件应留在各自任务中；使用材料还需要遵守其许可或授权范围。

## 验证与反馈

结构校验能检查技能文件是否完整，实际制作质量仍需用具体任务验证。请按[验收标准](skills/method-ppt/references/quality-checks.md)核对输出，尤其是原文依据、公式完整性、图表可读性和口播页序。

改进建议与脱敏案例见 [贡献说明](CONTRIBUTING.md)。维护者发布前可使用[发布检查清单](docs/publishing.md)。
